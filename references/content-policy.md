# 公众号内容规范

| 类型 | 推荐字数 | 结构 |
|---|---:|---|
| 快讯/通知 | 400–900 | 事实、影响、必要行动 |
| 互动引流 | 800–1500 | 钩子、问题、价值、主 CTA |
| 活动招募 | 1000–1800 | 受众、收益、流程、报名信息 |
| 产品/服务 | 1200–2500 | 问题、方案、证据、边界、CTA |
| 案例复盘 | 1500–3000 | 背景、动作、结果、原因、经验 |
| 教程/方法论 | 1800–3500 | 目标、步骤、示例、避坑 |
| 深度观点/行业分析 | 2500–5000 | 论点、数据、机制、反方、方向 |
| 访谈/人物 | 2500–6000 | 人物、事件、转折、原话、启示 |

字数是信息量目标，不是填充目标。资料不足时应明确指出缺少的证据、范围或对象。

每个进入核心论证的数据需要：来源、日期、统计口径、单位、样本/范围、比较基准、变化、主题关联、机制、替代解释、限制、影响、方向和可信度。深度观点和行业分析需要至少两组独立证据簇，且至少一处反方或替代解释。

内容包中，事实通过 `source_id` 追溯到来源；正文块通过 `fact_refs` 与 `insight_refs` 引用它们。事实、推断和观点必须分开标记：直接引文保持原文，推断明确说明依据与限制。两个“证据簇”不能只是同一来源换两个标签，必须至少覆盖两个独立来源。

互动引流每篇仅一个主 CTA，可有一个次 CTA。评论关键词、二维码、链接、表单、名额和截止时间都必须由用户提供或由可信来源支持；不能为了转化凭空补写。
